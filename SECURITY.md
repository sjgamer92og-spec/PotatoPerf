# Security

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue, comment or discussion with the details.

- **Private contact:** coming soon. The Modrinth page will carry the private reporting address when it is live.
- Until that channel exists, open a report on the Modrinth page asking for a private contact and keep the technical
  details out of the public text.

Please include:

- the PotatoPerf version and the exact Minecraft version you use;
- your launcher and device;
- what an attacker could do with the problem;
- the smallest steps that reproduce it.

Do not attach your full game directory. The report bundle from Settings -> Logs -> **Export report bundle** is enough;
it contains no username, server address or exact coordinates.

## Scope

PotatoPerf is a client-side mod. It does not run a server, accept network connections, or send your data anywhere.
Reports about Minecraft itself, Fabric Loader, Fabric API or another mod belong with those projects.

## Supported versions

Only the current release is supported. Check the supported versions table in the README for the exact game versions,
and always use the newest PotatoPerf release for your game version.
