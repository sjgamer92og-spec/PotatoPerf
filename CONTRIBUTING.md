# Contributing

## Code contributions

Code contributions are not accepted. PotatoPerf is closed source (All Rights Reserved) and the source code is not
public, so there is no pull-request workflow and patches cannot be reviewed or merged.

## Bugs and ideas

Bug reports and feature ideas are welcome as GitHub issues on the repository:
https://github.com/sjgamer92og-spec/PotatoPerf/issues

Please:

- open one report per problem, with a clear title;
- say which PotatoPerf version and which Minecraft version from the supported versions table you use;
- name your device, launcher and renderer;
- attach the report bundle.

## The report bundle

1. Start the game and reproduce the problem.
2. Open the settings with `Right Shift + O`.
3. Go to **Logs** and choose **Export report bundle**.
4. Attach the zip from `potatoperf/exports` to your report.

The bundle contains the session summary, one CSV row per second, spike entries, events and a diagnostics file. It
contains no username, home path, server address or exact coordinates.

## Ideas and compatibility requests

Requests for a specific device, launcher or renderer are useful. Say what happens, what you expected, and whether the
same thing happens with the overlay off and with **Safe mode** enabled.
